Accessibility Statement

Last updated July 22, 2026.

Commitment

This infrastructure map is designed to support WCAG 2.1 Level AA and to use selected WCAG 2.2 improvements for keyboard focus, target size, contrast, reduced motion, and non-color visual cues.

Accessibility Features

The map includes skip links, labeled search and filter controls, keyboard-accessible data-center results, live detail updates, named map markers, high-visibility focus styles, reduced-motion handling, and text alternatives for map-based status information.

Known Limitations

The optional power-plant layer is optimized as a viewport-rendered visual layer. A full accessible table for all power-plant records should be added if users need to browse that complete layer without the map.
